## 계약·화면 연결 확인

- A-1 → A-2: [QR 테스트 벡터](../contracts/qr-test-vectors.json)를 공통 정답으로 사용한다. ASCII JSON, 키 순서 `v,rn,sn,ap,md,rg,cn`, 공백 없음, 업체명 UTF-8 Base64 URL-safe(패딩 제거), SHA-256 앞 8자리 체크값을 따른다. 변조·지원하지 않는 버전은 A-2가 거부한다.
- B-1 → B-2: [OpenAPI](../api/field-server.openapi.yaml)가 설명 문서보다 우선한다. 휴대폰은 `:8765/api/v1`, 관리는 `127.0.0.1:8766/api/admin/v1`; 화면도 해당 서버에서 제공한다. 단말·세션은 HttpOnly 쿠키를 사용한다.
- MO-04·05: 분류·촬영 항목은 `/categories` 응답을 사용한다. `categories.yaml`의 원본은 ktl-field-modules에 있으며 이 검토에서는 변경하지 않는다.
- MO-05: 원본 해상도로 업로드하고 같은 업로드 재시도는 같은 `client_upload_id`를 사용한다. `202 queued`, 중복 `409 DUPLICATE_UPLOAD`, 연결 복구 후 자동 재시도 3회를 처리해야 한다.
- MO-05·06: SSE `photo.status`·`photo.values`로 갱신하고 값은 사진 상세로 다시 받는다. 확인 필요 값은 사진과 대조하고 수정 사유를 입력해야 확정할 수 있다.
- AD-01·04·05: 확인 필요 목록, 미확정 값이 있는 건의 완료 차단, 내보내기 미리보기·다운로드, 등록 코드·단말·시험자 관리를 확인했다. 관리 경로는 OpenAPI의 실제 경로를 사용한다.
- AD-02·03(S): 서버가 Selector 계산을 수행한다. 프론트 계산은 미리보기이며 판정은 하지 않는다. 차트 라이브러리는 로컬 번들에 포함한다.
- 전 파트: 인터넷·CDN 호출 금지, 원본 읽기 전용·SHA-256 기록, 값의 출처 추적, 시험자 확인 후 확정, 파일 내용 기반 판별을 지킨다. 실제 견본·개인정보는 커밋하지 않는다.
